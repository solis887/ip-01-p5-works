## 创作说明

**几何构成。** 画面用 380 × 570 的竖幅构图，一条米白竖条贯穿中轴，稳定整个版面。上半部用一个最大面积的浅蓝圆压住重量，右上用小一号的米白圆叠压，咬合出月牙形的负空间；左右两处橘红圆一上一下互相呼应，把视线从左上引到右下。配色只有 5 个：暖色（橘红、浅黄）负责跳出来，冷色（浅蓝）负责退后，米白与深灰做间隔，是明确的冷暖对照。中部的两个深灰圆是「挖空」，让前后层次分明，而不是所有形状都堆在一个平面上。所有圆写在一张坐标表里，由 for 循环统一绘制，改一个数字就能整体调整疏密。

**圆的呼吸。** 开场时 16 个圆从画布中心弹性散开（`easeOutBack` 缓动），之后持续互相弹跳。三种交互：左右移动鼠标，通过 `map()` 把鼠标位置换成 0.2～1.6 的运动速度倍率；点击画布时，以点击点为圆心计算每个圆的距离，越近推力越大，形成一次冲击波；圆形本身随时间做正弦呼吸，大小缓慢起伏。边界用条件判断做反弹，并把位置夹在画布内，避免圆卡在边缘抖动。
